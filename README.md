# 원더래빗 (WonderRabbit)

> AI와 함께 넓히는 시선, 균형 있게 바로 세우는 나만의 관점

같은 뉴스를 여러 언론사가 어떻게 다르게 다뤘는지 비교하고,
질문하는 토끼 **오호**와 정리하는 토끼 **아하**와 함께 생각을 넓히는 청소년 뉴스 리터러시 웹이에요.

## 체험하기
https://2jane22.github.io/wonderrabbit/

## 이런 걸 할 수 있어요
- 분야별 뉴스(12개 분야)를 쉬운 요약으로 읽기
- 어려운 낱말 뜻 보기, 끊어 읽기 퀴즈
- 언론사별로 무엇을 먼저 다뤘는지 비교하기
- 읽은 직후와 대화한 뒤, 두 번 내 생각의 위치를 짚어보기
- 오호와 대화하고, 아하가 정리해 주는 생각 이어가기
- 생각 정리 노트(같은 기사를 다시 생각하면 회차별로 쌓여요), 단어장, 한 줄 평, 에세이가 모이는 나의 포트폴리오
- 포인트와 배지, 처음 시작할 때 보는 사용법 안내

## 원더래빗 뉴스 원칙
1. 언론사 기사만
2. 혐오 표현 없이
3. 갈등 부추기지 않기
4. 한쪽 편 들지 않기
5. 청소년에게 안전하게
6. 개인정보 지키기
7. 베끼지 않고 출처 밝히기
